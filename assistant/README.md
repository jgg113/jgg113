# 클로드비서 — 비서 "수빈이" (24시간 듣는 한국어 AI 비서, 안드로이드)

앱 이름은 **클로드비서**, 비서 이름은 **수빈이**, 전화가 올 때 이름은 **클로드 수빈이** 입니다.

휴대폰을 켜 두기만 하면 곁에서 오가는 한국어 대화를 계속 듣다가

1. **일정·약속이 나오면** ("내일 3시에 치과", "다음 주 화요일 저녁에 민수랑 밥") 실제 날짜·시각으로 바꿔 **삼성 캘린더(삼성 계정)에 등록**하고,
   직접 말하지 않았어도 챙겨야 할 것 같은 일("치과 가 봐야 되는데", "주말에 영화 볼까", "다음 주에 출장 가")은 **"캘린더에 추가할까요?"** 하고 알림으로 물어보고
   ([캘린더에 추가] [알림만] [아니요], 앱에서는 날짜·시각을 바꿔서 넣기도 가능),
2. **그 시각이 다가오면** 미리 알림(기본 30분 전)과 정각 알림을 띄우고, 원하면 알림 버튼 하나로 **삼성 시계 앱 알람**도 넣고,
3. **흘려들은 중요한 말**(금액·계좌·주소·결정 사항·부탁받은 일)을 요약·핵심·할 일로 정리해 두고, 중요한 건 바로, 나머지는 **하루 요약 알림**(기본 밤 9시)으로 알려 주고,
4. **일정 요약**: 아침마다(기본 8시) 오늘 일정 브리핑, 오늘 탭에서 오늘·내일 / 이번 주 / 다음 주 요약 (삼성 캘린더에 직접 넣은 일정까지 모두),
5. **"이번 주 일정 뭐 있어?"**, **"아까 팀장님이 보고서 언제까지라고 했지?"** 처럼 물어보면 캘린더와 기록을 찾아 답해 주는 앱입니다.

### 기록: 요약 → 전문 보기 → 그때 소리 듣기

들은 말과 통화를 **대화 묶음**(5분 넘게 조용하면, 또는 통화가 시작·끝나면 새 묶음)으로 나눠 기록 탭에 보여 줍니다.
- 묶음마다 **언제·누구와**(💬 곁에서 들은 대화 / 📞 엄마 님과 통화), **요약·핵심·할 일·넣은 일정**이 먼저 나옵니다. 정리 노트가 없는 짧은 대화도 바로 요약해 보여 줍니다.
- **[전문 보기 ⌄]** 를 누르면 받아쓴 원문 전체가 펼쳐집니다. **줄을 누르면 그때 소리를 들려주고**, **[▶ 전체 듣기]** 는 그 대화를 처음부터 이어서 들려줍니다. 맥락이 헷갈릴 때 직접 들어 보세요.
- 줄을 **길게 누르면** 받아쓴 글을 고치거나, **누가 말했는지(🙋 나 / 👤 상대)** 바로잡거나, 그 줄을 지울 수 있습니다. 고친 낱말은 다음부터 자동으로 바로잡고, "내 말"로 고른 줄은 그때 녹음으로 내 목소리를 더 배웁니다.
- 목소리를 등록했다면 줄마다 **🙋 나 / 👤 상대** 가 붙습니다.
- **지우기**: 대화 묶음 카드의 🗑 (그 대화의 글·녹음·요약), 기록 탭 위 🗑 (그날 전부), 줄 길게 누르기 → [이 줄 지우기]. 캘린더에 넣은 일정은 그대로 둡니다.
- 📞 통화 카드의 ↻ **[다시 받아쓰기]**: 원래 통화 녹음 파일을 지금 모델로 다시 처리합니다 (그 통화에서 저절로 넣은 일정도 지우고 새로 정리).
- **녹음은 최근 3일치를 늘 보관**합니다 (설정 → 녹음 보관에서 끔·3·7·14일). 조용한 시간은 저장하지 않아 하루 대화 3시간이면 40MB 안팎입니다. 날짜 칩의 🎧 표시가 녹음이 남아 있는 날입니다.
- 일정 근거 화면의 앞뒤 대화도 눌러서 들을 수 있습니다. 위 오른쪽 [공유]로 그날 기록을 글로 내보낼 수 있습니다.

### 내 목소리 등록 (오늘 탭 [🙋 내 목소리] 또는 설정 맨 위)

문장 3개(각 6초)를 소리 내어 읽으면 수빈이가 목소리 특징을 기억합니다 (3D-Speaker CAM++ 모델 28MB, 처음 한 번 받음).
그다음부터 받아쓴 말마다 **나 / 상대**를 가리고, 말한 사람이 바뀌면 줄을 나눕니다.
- **내 목소리로 한 약속**은 더 믿고(확신도 +), **다른 사람·TV 목소리**에서 나온 일정은 덜 믿어 먼저 물어봅니다. 근거 화면에 "등록한 내 목소리로 한 말이에요 (비슷함 87%)"처럼 적힙니다.
- 한국어 화자 10명으로 시험했을 때 조용한 곳·먼 거리+소음 모두 사람을 틀리지 않았습니다 (비슷함 50% 이상이면 나, 35% 아래면 상대).
- 등록 뒤 [확인해 보기]로 몇 % 비슷한지 바로 볼 수 있고, [더 읽기]로 문장을 더하면 시끄러운 곳에서도 더 잘 알아봅니다. 목소리 특징은 휴대폰에만 저장합니다.

### 수빈이가 한 말은 받아쓰지 않아요

예전 버전은 수빈이가 스피커로 말한 내용(목소리 미리 듣기 "오늘 오후 3시에 민수 약속이 있어요", 전화 안내)을 다시 받아써서 일정으로 넣을 수 있었습니다.
이제 수빈이가 말하는 동안(+ 끝난 뒤 2초) 들어온 소리는 버리고, 그래도 들어온 말이 수빈이가 방금 한 말과 같으면 한 번 더 버립니다. 업데이트하면 그렇게 잘못 들어간 일정을 한 번 찾아 지웁니다.

### 통화 녹음도 정리 (설정 → 통화 녹음 정리)

통화 중에는 안드로이드가 다른 앱의 마이크를 막아 수빈이가 직접 못 듣습니다. 대신 **삼성 전화 앱의 통화 자동 녹음 파일**(내장 저장공간 `Recordings/Call`)을 지켜보다가,
통화가 끝나 파일이 저장되면 10초 뒤 받아써서 일정·할 일·중요한 말을 정리합니다. 기록 탭에 "📞 엄마 님과 통화" 묶음(요약 + 전문 + 다시 듣기)과 알림이 생기고, 일정은 위와 같은 방식으로 넣거나 묻습니다.
- 처음 켜면 최근 하루치 녹음부터 처리합니다. 녹음 파일은 읽기만 하고 고치거나 지우지 않습니다.
- **두 사람 목소리로 나눠** 받아씁니다: 통화 녹음은 두 사람 소리가 한 줄에 섞여 있어서, 1.5초 창을 0.5초씩 옮기며 목소리 특징을 뽑아 둘로 묶고 말한 사람이 바뀌는 곳(그 근처 가장 조용한 순간)에서 자릅니다. 둘 중 **등록한 내 목소리에 더 가까운 쪽**을 🙋 나로 정합니다 — 전화망을 거친 소리는 등록한 목소리와 꽤 달라서, 정해진 기준(50%)으로 보면 내 말도 "상대"가 되던 문제를 고쳤습니다.
- 한 통화 안에서 같은 날 여러 번 나온 시각("점심쯤부터", "한 시 조금 전에", "열두 시에서 한 시 사이")은 **약속 하나로 합치고**, 앞에서 말한 날짜("화요일 날")를 뒤의 시각에 이어 씁니다. 상대가 자기 일정을 말한 것("내일도 약속 있어", "내가 픽업하러 가야 돼")은 넣지 않습니다.
- 전화 음질이라 곁에서 들은 말보다 받아쓰기가 조금 더 틀립니다.

### 수빈이와 음성 대화

전화를 받은 뒤(또는 오늘 탭의 **[📞 수빈이와 통화]**) 말로 대답·부탁할 수 있습니다. 휴대폰의 음성 인식(삼성/Google, 무료)을 씁니다.

| 이렇게 말하면 | 수빈이가 |
|---|---|
| "10분 뒤에 다시 알려줘", "나중에 다시" | 그만큼 뒤에 다시 전화 |
| "다시 말해줘", "뭐라고?" | 다시 읽기 |
| "자세히 말해줘" / "짧게" | 그 통화에서만 길이 바꿔 다시 읽기 |
| (일정 물어볼 때) "응 넣어줘" / "알림만" / "아니 필요 없어" | 캘린더에 넣기 / 알림만 / 넣지 않기 |
| "내일 오후 세 시에 치과 일정 넣어줘", "30분 뒤에 빨래 꺼내라고 알려줘" | 바로 일정·알림 등록 |
| "이번 주 일정 뭐 있어?", "내일 약속 있어?" | 캘린더 읽어 주기 |
| "팀장님이 보고서 언제까지라고 했지?" | 기록에서 찾아 대답 |
| "고마워", "알겠어" | 인사하고 끊기 |

### 전화로 알려 주기 (설정 → 수빈이 전화·목소리)

일정 미리 알림(기본 30분 전)과 아침 브리핑 때 **클로드 수빈이**가 삼성 수신 전화 화면처럼 벨을 울립니다. 초록 버튼을 밀어서 받으면 밝은 목소리로 읽어 줍니다.
- **간단히** (기본): "수빈이예요! 30분 뒤 오후 3시, 민수 약속이에요."
- **자세히**: "안녕하세요, 수빈이예요! 30분 뒤 오후 3시에 강남역에서 민수 약속 일정이 있어요. 전에 '…'라고 하셨거든요. 지금 준비하시면 딱 좋아요!" (브리핑은 내일 일정까지)
- 목소리: 휴대폰의 한국어 음성(삼성·Google TTS) 중 가장 자연스러운 것을 자동으로 고르고, 조금 높고 경쾌하게 읽습니다. 설정에서 목소리·높이·빠르기를 고르고 미리 들을 수 있습니다.
- 통화 화면에서 [다시 듣기] [자세히/간단히] [말하기] [10분 뒤], 물어보는 일정의 [네, 넣어 줘] [알림만] [아니요]를 누를 수도 있습니다.
- 40초 안에 안 받으면 '부재중' 알림으로 남고, 진짜 통화 중이면 벨 대신 보통 알림으로 알립니다.
- 안드로이드 14 이상은 설정에서 **전체 화면 알림**을 허용해야 화면이 꺼져 있을 때도 전화 화면이 뜹니다. 목소리는 휴대폰의 한국어 음성 엔진(삼성/Google TTS)을 씁니다.

### 일정 근거 보기 / TV 소리 거르기

오늘 탭의 일정 카드나 일정 알림(**[근거 보기]**)을 누르면 그 일정을 왜 넣었는지 볼 수 있습니다.
- **왜 넣었나요?** 바로 넣었는지(확신도 %), 물어본 뒤 승인했는지, 통화에서 말로 부탁했는지
- **들은 때·어디서**: 날짜·시각, 곁에서 들은 말인지 📞 통화 녹음인지
- **들은 말**과 **판단 근거**: 찾은 날짜·시각 말('내일', '오후 세 시'), 약속 말('만나'), 확정 말('기로 했'), 짐작한 부분, 감점 이유
- **앞뒤 대화**: 그때 받아쓴 원문 (근거 줄 강조)
- **[맞아요] [날짜·시간 고치기] [❌ 실제 약속이 아니에요 — 지우기]** — 지우면 캘린더에서도 지우고, 같은 말로 다시 넣지 않으며, "앞으로 늘 물어볼까요?"를 묻습니다.
- 삼성 캘린더의 일정 메모에도 들은 때·들은 말·판단 근거가 적힙니다.

TV를 켜 두면 드라마 대사도 약속처럼 들릴 수 있어서, **10분 중 6분 넘게 말소리가 쉬지 않고 이어질 때** 들은 일정과 방송에 흔한 말(채널·광고·시청자·홈쇼핑 등)이 섞인 일정은 **어떤 모드에서도 바로 넣지 않고 먼저 물어봅니다** ("📺 TV·영상 소리일 수 있어요" 표시).

### 일정을 넣는 방식 (설정 → 캘린더·알림)

| 방식 | 확실한 약속 ("내일 3시에 민수랑 만나기로 했어") | 애매한 말 ("주말에 영화 볼까", "다음 주에 출장 가") | 언제인지 모르는 일 ("치과 가 봐야 되는데") |
|---|---|---|---|
| **알아서** (기본) | 바로 넣고 알림 ([취소] 버튼) | "추가할까요?" 묻기 | "챙겨 드릴까요?" 묻기 ([내일 아침 9시에 알림] / 날짜 정하기) |
| 늘 묻기 | "추가할까요?" 묻기 | 묻기 | 묻기 |
| 바로 넣기 | 바로 넣기 | 웬만하면 바로 넣기 | 묻기 |

"아니요"라고 한 일정은 다시 묻지 않습니다. "회의 네 시로 미뤄졌어"처럼 바뀐 말은 "일정을 옮길까요?"로 묻거나(확실하면 바로) 옮깁니다.

## 무료·무제한 모드 (기본값)

API 키도, 요금도, 사용 한도도 없습니다. 모든 처리를 휴대폰 안에서 합니다.

| 하는 일 | 쓰는 것 (모두 무료 공개 모델) | 크기 |
|---|---|---|
| 한국어 받아쓰기 (기본) | [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) + [한국어 대화 Zipformer 174M](https://huggingface.co/kangkyu/icefall-asr-ko-streaming-zipformer-174m) (Apache-2.0, KsponSpeech+AIHub 한국어 6,500시간으로 학습) | 처음 한 번 160MB |
| 띄어쓰기 | 앱에 들어 있는 작은 띄어쓰기 모델 (한국어 자막·TED 글 650만 문장으로 직접 학습, 글자 n-gram 로지스틱 회귀) | 2MB |
| 통화 목소리 나누기 | [3D-Speaker CAM++](https://github.com/modelscope/3D-Speaker) 목소리 특징 + 두 묶음 나누기 (내 목소리 등록과 같은 모델) | 28MB |
| 다른 받아쓰기 모델 (선택) | [Dolphin](https://github.com/DataoceanAI/Dolphin) base 105MB, [Qwen3-ASR 0.6B](https://huggingface.co/Qwen/Qwen3-ASR-0.6B) 약 1GB (한국어로 고정) | |
| 말소리 감지 | [Silero VAD](https://github.com/snakers4/silero-vad) (MIT) — 소리 크기가 아니라 사람 목소리인지로 판단 | 0.6MB |
| 일정·할 일·중요한 숫자 찾기 | 앱에 들어 있는 한국어 날짜·시각 규칙 ("내일 오후 세 시", "다음 주 화요일 저녁 일곱 시 반", "삼십 분 뒤", "십일월 오일", "금요일까지", "네 시로 미뤄졌어") | 0 |
| 요약 문장 다듬기 (선택, 실험 기능 — 기본 끔) | [MediaPipe LLM Inference](https://ai.google.dev/edge/mediapipe/solutions/genai/llm_inference/android) + [Qwen2.5-1.5B-Instruct](https://huggingface.co/litert-community/Qwen2.5-1.5B-Instruct) (Apache-2.0) | 1.6GB |
| 묻기 탭 | 기록에서 낱말 찾기 (+ 요약 AI 가 있으면 답 문장으로) | 0 |

더 똑똑한 정리가 필요하면 설정에서 받아쓰기를 **클라우드 API**(Groq·OpenAI), 정리를 **Claude**로 바꿀 수 있습니다 (유료·한도 있음).

### 한국어 받아쓰기 정확도 (직접 잰 값)

**1.0.10: 실제 대화·통화 기준으로 다시 골랐습니다.** 아래 1.0.9 표는 또박또박 읽은 문장이라 실제 대화와 달랐고, 사용자의 실제 통화 녹음에서 크게 틀렸습니다.
그래서 일상 대화 녹음(KsponSpeech 평가 세트 150문장)과, 같은 녹음을 전화 음질(8kHz GSM 코덱)로 바꾼 것으로 다시 쟀습니다. 숫자는 글자 오류율(CER, 낮을수록 좋음).

| 모델 (휴대폰 안, 무료) | 크기 | 일상 대화 | 전화 음질 | 빠르기 |
|---|---|---|---|---|
| Dolphin base (1.0.9 기본) | 105MB | 14.8% | 17.9% | 아주 빠름 |
| Qwen3-ASR 0.6B (1.0.9 고정밀) | 약 1GB | 13.3% | 20.8% | 느림 |
| Qwen3-ASR 0.6B, 한국어로 고정 | 약 1GB | 12.7% | 17.0% | 느림 |
| Qwen3-ASR 1.7B, 한국어로 고정 | 2.4GB | 9.4% | **12.2%** | 아주 느림 |
| 한국어 대화 Zipformer 72M | 70MB | 8.9% | 36.6% | 빠름 |
| **한국어 대화 Zipformer 174M (새 기본)** | 160MB | **8.1%** | 12.6% | 빠름 |

사용자의 실제 통화 녹음(2분 17초)에서 고친 것:
- **이름 힌트가 헛말을 만들었습니다.** Qwen3 에 "자주 나오는 이름"을 힌트로 줬더니, 알아듣기 어려운 짧은 소리마다 힌트 목록을 그대로 적었습니다("홍길동 길동 길동이 길동아 홍과장 홍과장님 ○○회사" 같은 식). 이제 받아쓰기 모델에 이름을 주지 않습니다.
- **Qwen3 가 한국어를 중국어로 적었습니다** ("12点到1点" — 정작 약속 시각인 "열두 시에서 한 시"). 앱이 그 줄을 버려 약속을 놓쳤습니다. 이제 한국어로 고정합니다.
- 새 기본 모델은 띄어쓰기를 거의 안 해서("알았어나도화요일끝나고바로연락할게"), 띄어쓰기 모델을 따로 만들어 붙였습니다.
- 스트리밍 모델이라 말 끝에 조용한 소리를 2.56초 붙여야 끝말까지 나옵니다 (0.64초면 오류가 두 배).

<details><summary>1.0.9 때 잰 값 (또박또박 읽은 문장)</summary>

공개 한국어 평가 음성(Google FLEURS 한국어 60문장, Zeroth 한국어 80문장)으로 비교했습니다.

| 예전 기본 Zipformer (소리 키운 뒤) | 85MB | 10.8% | 15.3% | 55.9% | 36.5% | 아주 빠름 |

알게 된 것과 고친 것:
- **작은 소리를 키우는 것만으로 오류가 58.8% → 10.8%** 로 줄었습니다. 받아쓰기용 마이크 경로는 자동 음량이 없어 1~2m 떨어진 말이 아주 작게 들어오는데, 휴대폰 안 모델은 작은 소리를 아예 받아쓰지 못했습니다. 이제 받아쓰기 전에 알맞은 크기로 키웁니다.
- 말소리 감지도 소리 크기 기준이라 작은 말을 통째로 놓쳤습니다 → 사람 목소리를 알아보는 Silero VAD 로 바꿨습니다.
- 기본 모델을 Dolphin 으로 바꿨습니다 (오류 절반, 시끄럽고 먼 소리에 훨씬 강함).
- 고정밀 모델(Qwen3)을 받아 두면 **일정·약속 같은 중요한 말만** 고정밀로 한 번 더 받아쓰고, **통화 녹음은 전부** 고정밀로 받아씁니다. 배터리는 조금만 더 씁니다.
- 잡음 제거 모델(GTCRN)도 시험했지만 오히려 오류가 늘어(11.2% → 13.9%) 넣지 않았습니다.

잘못 받아쓴 말은 **기록 탭에서 그 줄을 길게 눌러 고치면**, 바뀐 낱말을 기억해 다음부터 자동으로 바로잡습니다 (설정 → 받아쓰기 → 자꾸 틀리는 말 고치기).

## 설치

1. 최신 APK: <https://github.com/jgg113/jgg113/releases/download/gyeot-latest/gyeot.apk>
   (이 브랜치에 커밋이 올라가면 GitHub Actions 가 자동으로 빌드합니다. 갤럭시용 64비트 ARM 전용.)
2. 설치 후 **오늘 탭의 '한국어 대화 전용 모델' [지금 받기]** (160MB, 와이파이에서 한 번). 예전 Dolphin·Qwen3 모델은 설정 → 받아쓰기에서 지울 수 있습니다.
3. **오늘 탭 → [듣기 시작]** → 마이크·캘린더·알림 권한 허용.
4. **오늘 탭 → [🎤 받아쓰기 시험]** 으로 잘 알아듣는지 확인하고, **[🙋 내 목소리]** 로 목소리를 등록합니다 (1분).
5. **갤럭시 필수 설정**: 설정 탭 → 24시간 듣기 → [배터리 최적화 제외]를 누르고, 휴대폰 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 클로드비서를 추가합니다. 안 하면 몇 시간 뒤 삼성이 앱을 재웁니다.
6. 설정 탭 → 캘린더·알림에서 일정을 넣을 캘린더로 **삼성 계정**을 고릅니다 (없으면 삼성 캘린더 앱에서 삼성 계정을 연결).

## 꼭 알아 둘 점

- **법**: 대한민국 통신비밀보호법상 *내가 참여한 대화*를 기록하는 건 괜찮지만, *내가 빠진 다른 사람들끼리의 대화*를 몰래 녹음·기록하면 불법입니다. 자리를 비울 때는 멈춰 두세요. 전화 통화는 안드로이드가 마이크를 막아 직접 들리지 않으므로, 삼성 통화 자동 녹음 파일로 정리합니다.
- **화자 구분**: 내 목소리를 등록하면 나 / 상대 두 가지로만 가립니다 (상대가 여럿이어도 모두 '상대'). 곁에서 들은 말이 나로 잘 안 잡히면, 기록 탭에서 내 줄을 길게 눌러 [🙋 나]를 고르세요 — 휴대폰을 둔 실제 자리의 소리로 내 목소리를 더 배웁니다.
- **배터리**: 하루 종일 마이크를 켜 두므로 평소보다 배터리를 더 씁니다(말소리 감지는 가볍지만 CPU 를 재우지 못함). 충전기에 자주 올려 두는 환경에 맞습니다.
- **무료 모드의 한계**: 규칙 엔진은 AI 처럼 맥락을 깊이 이해하지 못합니다. "내일 세 시 치과"처럼 날짜·시각이 들어간 약속은 잘 잡지만, 돌려 말한 약속은 놓치거나 제목이 투박할 수 있습니다. 받아쓰기도 시끄러운 곳·먼 거리에서는 틀립니다. 기록 탭에서 확인하고, 잘못 들어간 일정은 [취소]로 지우세요.
- **인터넷**: 무료 모드는 모델을 받은 뒤 인터넷이 필요 없습니다. 클라우드·Claude 모드는 인터넷이 있어야 합니다.
- 실제 갤럭시 기기에서 아직 오래 돌려 보지 않았습니다. 처음 며칠은 '기록' 탭에서 받아쓰기 품질을, '오늘' 탭에서 일정이 맞게 들어가는지 확인해 주세요.
