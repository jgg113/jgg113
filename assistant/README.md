# 곁비서 (24시간 듣는 한국어 AI 비서, 안드로이드)

휴대폰을 켜 두기만 하면 곁에서 오가는 한국어 대화를 계속 듣다가

1. **일정·약속이 나오면** ("내일 3시에 치과", "다음 주 화요일 저녁에 민수랑 밥") 실제 날짜·시각으로 바꿔 **삼성 캘린더(삼성 계정)에 등록**하고,
   직접 말하지 않았어도 챙겨야 할 것 같은 일("치과 가 봐야 되는데", "주말에 영화 볼까", "다음 주에 출장 가")은 **"캘린더에 추가할까요?"** 하고 알림으로 물어보고
   ([캘린더에 추가] [알림만] [아니요], 앱에서는 날짜·시각을 바꿔서 넣기도 가능),
2. **그 시각이 다가오면** 미리 알림(기본 30분 전)과 정각 알림을 띄우고, 원하면 알림 버튼 하나로 **삼성 시계 앱 알람**도 넣고,
3. **흘려들은 중요한 말**(금액·계좌·주소·결정 사항·부탁받은 일)을 요약·핵심·할 일로 정리해 두고, 중요한 건 바로, 나머지는 **하루 요약 알림**(기본 밤 9시)으로 알려 주고,
4. **일정 요약**: 아침마다(기본 8시) 오늘 일정 브리핑, 오늘 탭에서 오늘·내일 / 이번 주 / 다음 주 요약 (삼성 캘린더에 직접 넣은 일정까지 모두),
5. **"이번 주 일정 뭐 있어?"**, **"아까 팀장님이 보고서 언제까지라고 했지?"** 처럼 물어보면 캘린더와 기록을 찾아 답해 주는 앱입니다.

### 일정을 넣는 방식 (설정 → 3. 캘린더·알림)

| 방식 | 확실한 약속 ("내일 3시에 민수랑 만나기로 했어") | 애매한 말 ("주말에 영화 볼까", "다음 주에 출장 가") | 언제인지 모르는 일 ("치과 가 봐야 되는데") |
|---|---|---|---|
| **알아서** (기본) | 바로 넣고 알림 ([취소] 버튼) | "추가할까요?" 묻기 | "챙겨 드릴까요?" 묻기 ([내일 아침 9시에 알림] / 날짜 정하기) |
| 늘 묻기 | "추가할까요?" 묻기 | 묻기 | 묻기 |
| 바로 넣기 | 바로 넣기 | 웬만하면 바로 넣기 | 묻기 |

"아니요"라고 한 일정은 다시 묻지 않습니다. "회의 네 시로 미뤄졌어"처럼 바뀐 말은 "일정을 옮길까요?"로 묻거나(확실하면 바로) 옮깁니다.

## 무료·무제한 모드 (기본값)

API 키도, 요금도, 사용 한도도 없습니다. 모든 처리를 휴대폰 안에서 합니다.

| 하는 일 | 쓰는 것 (모두 오픈소스) | 크기 |
|---|---|---|
| 한국어 받아쓰기 | [sherpa-onnx](https://github.com/k2-fsa/sherpa-onnx) + Zipformer 한국어 모델 (KsponSpeech 한국어 일상 대화 969시간으로 학습, Apache-2.0) | 처음 한 번 85MB |
| 일정·할 일·중요한 숫자 찾기 | 앱에 들어 있는 한국어 날짜·시각 규칙 ("내일 오후 세 시", "다음 주 화요일 저녁 일곱 시 반", "삼십 분 뒤", "십일월 오일", "금요일까지", "네 시로 미뤄졌어") | 0 |
| 요약 문장 다듬기 (선택) | [MediaPipe LLM Inference](https://ai.google.dev/edge/mediapipe/solutions/genai/llm_inference/android) + [Qwen2.5-1.5B-Instruct](https://huggingface.co/litert-community/Qwen2.5-1.5B-Instruct) (Apache-2.0) | 1.6GB, 최신 갤럭시 S 권장 |
| 묻기 탭 | 기록에서 낱말 찾기 (+ 요약 AI 가 있으면 답 문장으로) | 0 |

더 똑똑한 정리가 필요하면 설정에서 받아쓰기를 **클라우드 API**(Groq·OpenAI), 정리를 **Claude**로 바꿀 수 있습니다 (유료·한도 있음).

## 설치

1. 최신 APK: <https://github.com/jgg113/jgg113/releases/download/gyeot-latest/gyeot.apk>
   (이 브랜치에 커밋이 올라가면 GitHub Actions 가 자동으로 빌드합니다. 갤럭시용 64비트 ARM 전용.)
2. 설치 후 **설정 탭 → 1. 받아쓰기 → '한국어 음성 인식' [받기]** (85MB, 와이파이에서 한 번).
   요약 AI 도 쓰려면 **2. 정리 → '요약 AI' [받기]** (1.6GB). 그다음 [작동 확인].
3. **오늘 탭 → [듣기 시작]** → 마이크·캘린더·알림 권한 허용.
4. **갤럭시 필수 설정**: 설정 탭의 [배터리 최적화 제외]를 누르고, 휴대폰 설정 → 배터리 → 백그라운드 사용 제한 → **절전 예외 앱**에 곁비서를 추가합니다. 안 하면 몇 시간 뒤 삼성이 앱을 재웁니다.
5. 설정 탭에서 일정을 넣을 캘린더로 **삼성 계정**을 고릅니다 (없으면 삼성 캘린더 앱에서 삼성 계정을 연결).

## 어떻게 동작하나

```
마이크(16kHz) ─▶ 말소리 감지(VAD) ─▶ 말 구간만 모아 25초 단위로 ─▶ 받아쓰기(휴대폰 안 Zipformer / 클라우드 Whisper)
                 조용할 땐 아무것도 안 보냄                          │  방송 자막 같은 헛인식 걸러냄
                                                                       ▼
            휴대폰에 날짜별로 저장 ◀────────────────────────────── 받아쓴 글
                    │
   대화가 1분 반 멈추면 (일정 냄새가 나면 20초 만에)
                    ▼
            정리: 휴대폰 안 한국어 규칙(+요약 AI) 또는 Claude — 요약 · 핵심 · 할 일 · 일정(날짜 계산, 확신도, 근거 문장)
                    │
      ┌─────────────┼──────────────────┐
      ▼             ▼                  ▼
 삼성 캘린더 등록   중요한 말 즉시 알림   하루 요약 알림
 (중복·지난 일정·    (importance=high)    (매일 지정 시각)
  확신도 0.6 미만 제외)
      │
 미리 알림 + 정각 알림 (정확 알람), [취소] [시계 알람도] 버튼
```

- **원본 음성은 저장하지 않습니다.** 무료 모드에서는 소리도 글도 휴대폰 밖으로 나가지 않습니다. 받아쓴 글과 정리는 휴대폰 안에만 있습니다(기본 30일 보관). 클라우드·Claude 를 고르면 그때만 그 서비스로 보냅니다.
- 상단의 **'곁비서가 듣는 중' 알림**에서 [잠시 멈춤]/[끄기], 빠른 설정 타일 **'곁비서 듣기'** 로 바로 멈출 수 있습니다.
- 재부팅되면 일정 알람을 다시 걸고 듣기를 다시 켭니다 (안드로이드 14+ 가 막으면 "눌러서 다시 듣기" 알림이 뜹니다).
- "묻지 않고 바로 캘린더에 넣기"를 끄면 일정을 찾았을 때 알림의 [캘린더에 등록]을 눌러야 들어갑니다.

## 비용

| 모드 | 하루 대화 3시간 기준 |
|---|---|
| 휴대폰 안 (기본) | 0원, 한도 없음 |
| 클라우드 받아쓰기 Groq Whisper | 무료 한도 안 (한도는 Groq 정책에 따라 바뀜) |
| Claude `claude-opus-5-5` | 약 1달러 안팎 (`claude-haiku-5-5` 면 몇십 원) |

## 꼭 알아 둘 점

- **법**: 대한민국 통신비밀보호법상 *내가 참여한 대화*를 기록하는 건 괜찮지만, *내가 빠진 다른 사람들끼리의 대화*를 몰래 녹음·기록하면 불법입니다. 자리를 비울 때는 멈춰 두세요. 전화 통화 음성은 안드로이드가 막아서 들리지 않습니다 (통화 요약은 삼성 통화 녹음·Galaxy AI 를 쓰세요).
- **화자 구분 없음**: 지금은 누가 말했는지 구분하지 않고, Claude 가 문맥으로 "내 일정인지"를 판단합니다. 설정에 **내 이름·호칭**과 **자주 나오는 이름**을 넣으면 정확도가 올라갑니다.
- **배터리**: 하루 종일 마이크를 켜 두므로 평소보다 배터리를 더 씁니다(말소리 감지는 가볍지만 CPU 를 재우지 못함). 충전기에 자주 올려 두는 환경에 맞습니다.
- **무료 모드의 한계**: 규칙 엔진은 AI 처럼 맥락을 깊이 이해하지 못합니다. "내일 세 시 치과"처럼 날짜·시각이 들어간 약속은 잘 잡지만, 돌려 말한 약속은 놓치거나 제목이 투박할 수 있습니다. 받아쓰기도 시끄러운 곳·먼 거리에서는 틀립니다. 기록 탭에서 확인하고, 잘못 들어간 일정은 [취소]로 지우세요.
- **인터넷**: 무료 모드는 모델을 받은 뒤 인터넷이 필요 없습니다. 클라우드·Claude 모드는 인터넷이 있어야 합니다.
- 실제 갤럭시 기기에서 아직 오래 돌려 보지 않았습니다. 처음 며칠은 '기록' 탭에서 받아쓰기 품질을, '오늘' 탭에서 일정이 맞게 들어가는지 확인해 주세요.

## 코드 구조 (`assistant/src/main/kotlin/io/github/jgg113/gyeot`)

| 파일 | 하는 일 |
|---|---|
| `audio/ListeningService.kt` | 마이크 포그라운드 서비스, 멈춤/재개, 웨이크락, 상태 알림 |
| `audio/SpeechSegmenter.kt` | 주변 소음을 따라가는 에너지 기반 말소리 감지 (앞 0.3초 포함, 1.2초 침묵이면 끊음) |
| `audio/Processor.kt` | 구간 묶기 → 받아쓰기 → 저장 → 정리 시점 판단 → 일정·알림 |
| `stt/LocalTranscriber.kt` | 휴대폰 안 한국어 받아쓰기 (sherpa-onnx Zipformer) |
| `stt/Transcriber.kt`, `stt/TranscriptFilter.kt` | OpenAI 호환 받아쓰기 API, 한국어 헛인식 거르기 |
| `ai/KoreanTime.kt`, `ai/RuleBrain.kt` | 한국어 날짜·시각 해석(한글 숫자 포함), 일정·할 일·핵심 규칙, 묻기 검색 |
| `ai/LocalLlm.kt` | 휴대폰 안 요약 AI (MediaPipe + Qwen2.5 1.5B), 쓸 때만 열고 닫음 |
| `ai/Analyzer.kt` | Claude (공식 Java SDK) 구조화 출력으로 정리, '묻기' 답변 |
| `ai/EventRules.kt`, `ai/ScheduleHints.kt` | 바로 넣기/물어보기/버리기 판단, 중복 검사, 일정 냄새 감지 |
| `ai/ScheduleSummary.kt` | 캘린더 일정 요약 (브리핑·오늘 탭·묻기), 질문 속 기간 읽기 |
| `data/ModelManager.kt` | 모델 파일 내려받기 (이어 받기) |
| `calendar/CalendarWriter.kt`, `calendar/EventRegistrar.kt` | 삼성 계정 캘린더 고르기·등록·삭제 |
| `alarm/*` | 정확 알람(미리·정각), 하루 요약, 알림 버튼, 재부팅 복구 |
| `ui/*` | 오늘·기록·묻기·설정 화면, 빠른 설정 타일 |

빌드: `./gradlew :assistant:testDebugUnitTest :assistant:assembleRelease`

## 다음에 붙이면 좋은 것

- **더 정확한 휴대폰 안 받아쓰기**: sherpa-onnx 가 지원하는 Qwen3-ASR 0.6B (한국어 포함 다국어, 약 880MB) 를 선택지로 추가.
- **화자 구분**: 내 목소리를 몇 문장 등록해 두고 구분(speaker embedding), 또는 네이버 CLOVA Speech 같은 화자 분리 지원 API.
- **갤럭시 워치**: 손목에서 일정 알림·멈춤 버튼.
- **반복 일정**("매주 월요일 회의"), 취소 말("내일 약속 취소됐어")을 기존 일정에 반영. (시각 변경 "4시로 미뤄졌어"는 이미 반영)
