# 주식노트 (안드로이드 앱)

국내 주식·미국 주식·코인(업비트 원화 마켓)을 한곳에서 보고, 차트·보조지표·매매전략 백테스트·매매신호·통계 예측·모의투자를 하는 **개인용** 주식 분석 앱입니다.
유료 주식 분석 앱에 흔한 기능(매매신호, 전략별 지표분석, AI 예측, 차트게임, 무제한 관심종목·보조지표)을 **공개된 무료 데이터와 이 앱이 직접 만든 계산**으로 구현했습니다. 다른 앱의 코드·디자인·데이터는 쓰지 않았습니다.
결제·로그인·실제 주문 기능은 없습니다.

## 설치 (휴대폰)

1. 늘 최신 APK 바로 받기: <https://github.com/jgg113/jgg113/releases/download/stocknote-latest/stocknote.apk>
   (빌드마다 `주식노트 1.0.N` 릴리스도 따로 올라갑니다: <https://github.com/jgg113/jgg113/releases>)
2. 내려받은 파일을 열어 설치합니다. 처음에는 "출처를 알 수 없는 앱 설치"를 허용해야 합니다.
3. 새 버전은 같은 방법으로 덮어 설치합니다. 공매비교 앱과 별개 앱이라 둘 다 설치할 수 있습니다.

## 기능

| 화면 | 기능 |
|---|---|
| **시장** | 국내·해외·코인 고르기, 지수(코스피·코스닥·코스피200 / SPY·QQQ·DIA), 상승·하락 종목 수, 상한가·하한가, 특징종목(급등·급락·거래대금), 테마 흐름(강한·약한 테마), 오늘의 주요 공시(DART), 시장 뉴스, 환율 |
| **관심** | 목록·종목 수 제한 없음, 목록 여러 개, 순서 바꾸기, 몇 초마다 시세 갱신, 가격 알림·신호 알림 모아 보기 |
| **종목 → 차트** | 1·5·15·60분·일·주·월봉, 두 손가락 확대·축소, 밀어서 과거 보기, 눌러서 그날 값 보기. 보조지표 26종을 **개수 제한 없이** 켜고 값을 바꿀 수 있음 (이동평균·지수이평·볼린저·엔벨로프·일목균형표·파라볼릭 SAR·돈치안·켈트너 / 거래량·RSI·MACD·스토캐스틱·윌리엄스 %R·CCI·DMI/ADX·ATR·OBV·MFI·ROC·모멘텀·TRIX·아룬·이격도·심리도·차이킨 머니플로·변동성). 고른 전략의 매수▲·매도▼ 시점 표시 |
| **종목 → AI 예측** | 0~100점 종합 점수와 의견(긍정적~부정적), 5일·20일 뒤 예상 주가(가운데 값·50%·80% 범위), 오를 확률과 평소 확률, **과거 적중률**, 점수 근거(통계 예측·추세·모멘텀·전략 신호·변동성·가치) |
| **종목 → 지표분석** | 직접 만든 전략 42개(추세·모멘텀·과매도 반등·돌파·거래량·캔들)를 이 종목의 과거 일봉으로 백테스트: 누적 수익률·승률·거래 수·최대낙폭·손익비·보유만 했을 때와 비교, 자산 곡선, 거래 내역, 지금 매수 쪽 신호 비율, 손절·익절 설정, **다음 신호 알림** |
| **종목 → 재무** (국내) | DART 사업보고서 3년 매출·영업이익·순이익 막대그래프, 영업이익률·순이익률·ROE·부채비율, 최근 분기, PER·PBR 추정 |
| **종목 → 이슈** | DART 공시(3개월)·뉴스, AI 이슈 요약 |
| **종목 → 정보·AI** | 시세 정보(52주 최고·최저, 기간 수익률 등), 속한 테마, **AI 에게 묻기**(앱이 계산한 숫자를 함께 보냄), 바깥 사이트 바로가기 |
| **종목 → 모의 매수·매도** | 가상 돈으로 지금 시세에 체결, 수수료·세금 반영. 실제 보유 종목 기록도 같은 창에서 |
| **발굴 → 매매신호** | 시가총액 상위(국내)·거래대금 상위(코인)·기본 목록(해외) 20~200종목 + 관심종목에서, 고른 전략이 최근 3봉 안에 낸 매수 신호를 **그 종목에서 그 전략의 과거 성과 순**으로 보여 줌. 전략별 1년 누적 수익률 그래프(보유만 했을 때와 비교), **새 매수 신호 알림** |
| **발굴 → 특징종목** | 급등·급락·거래대금·거래량·거래량 급증·52주 신고가·신저가·갭 상승·상한가·시가총액 (한국투자증권 실전 키가 있으면 거래대금·거래량은 실시간 순위) |
| **발굴 → 테마** | 기본 테마 34개(반도체·2차전지·방산·조선·전력설비·원자력·로봇·미국 빅테크·밈 코인 등)의 오늘 평균 등락률 순위, 테마별 종목, **내 테마 만들기·고치기** |
| **발굴 → 종목필터** | 시장·가격·등락률·시가총액·거래대금·PER + 차트 조건(이평선 위, RSI 범위, 거래량 배수, 1년 고가 근처, 골든크로스, 전략 매수 신호) |
| **투자 → 투자현황** | 모의계좌(원화 1억 + 10만 달러로 시작, 시드 무제한 추가)·실제 보유목록 여러 개, 총자산·평가손익·실현손익·종목 비중·거래 기록 |
| **투자 → 차트게임** | 이름·날짜를 숨긴 실제 과거 차트에서 40봉 동안 사고팔아 '들고만 있기'를 이기는 게임, '오를까 내릴까' 퀴즈, 기록 |
| **설정** | 키 넣기·연결 점검(안 되는 곳은 신청 페이지로 이동), AI 해설 연결, 알림(15분~3시간 간격), 수수료·세금, 저장 공간 |

코인(업비트)·뉴스·환율은 **키 없이** 바로 됩니다.

| 키 | 쓰는 곳 | 받는 곳 |
|---|---|---|

| DART 인증키 | 공시·재무제표 | [DART Open API](https://opendart.fss.or.kr/) 회원가입 후 인증키 신청 |

키를 넣고 [저장] → [연결 점검]을 누르면 출처마다 되는지 바로 확인합니다.

## 알아 둘 점

- **국내 무료 시세는 실시간이 아닙니다.** 공공데이터포털은 다음 영업일 오후에 전날 종가를 올립니다. 실시간은 한국투자증권 키가 있어야 합니다.
- **AI 예측은 통계 참고값입니다.** 지금과 지표 상태가 비슷했던 과거 장면(최근접 이웃 30개)의 이후 움직임을 모은 값이며, 같은 방법의 과거 적중률을 함께 보여 줍니다. 적중률이 50%대면 동전 던지기와 큰 차이가 없습니다.
- **백테스트**는 종가에 신호를 보고 다음 거래일 시가에 사고판다고 가정하며, 수수료·세금(설정에서 바꿈)을 뺍니다. 과거 성과가 미래 수익을 보장하지 않습니다.
- **알림**은 안드로이드 제한으로 15분보다 자주 확인할 수 없고, 배터리 절약 중에는 늦을 수 있습니다.
- 기본 테마는 업종·사업 내용으로 직접 묶은 대표 종목이라 빠진 종목이 있을 수 있습니다. 테마 화면에서 고쳐 쓰세요.
- 매매신호를 다른 사람에게 돈을 받고 제공하면 유사투자자문업 신고 대상이 될 수 있습니다. 이 앱은 개인 참고용입니다.
- 키·관심종목·계좌·알림은 모두 휴대폰에만 저장됩니다.

## 구조

| 경로 | 내용 |
|---|---|
| `core/` | 순수 Kotlin. 지표(Indicators), 전략 42개(Strategies), 백테스트(Backtester·IndicatorReport), 매매신호 스캔(SignalScanner), 통계 예측(Forecaster), 차트 지표 목록(IndicatorType), 차트게임, 모의투자(PaperBroker), 특징종목·종목필터(MarketStats·Screener), 테마, 데이터 출처(UpbitClient·PublicDataClient·KisClient·TwelveDataClient·DartClient·NewsClient·FxClient), 캐시·출처 선택(MarketData), AI(Gemini·OpenAI 호환) + 단위 테스트 |
| `app/` | Jetpack Compose 앱 (시장·관심·발굴·투자·설정, 종목 상세, Canvas 캔들 차트, WorkManager 알림) |
| `../.github/workflows/stock.yml` | `stock/` 이 바뀌면 테스트 → APK → `stock-N` 릴리스와 고정 링크 `stocknote-latest` 갱신 (공매비교의 latest 링크는 건드리지 않음) |

로컬 빌드 (Android SDK, JDK 17+):

```
cd stock
./gradlew :core:test :app:assembleRelease
LIVE=1 ./gradlew :core:test --tests '*LiveTest*'      # 실제 업비트 자료로 전체 흐름 확인
./gradlew :app:testDebugUnitTest -PscreenTests          # 화면 스크린샷 (build/screenshots)
```
